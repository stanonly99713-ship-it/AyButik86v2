# AyButik86 — сайт магазина посуды

Витрина-каталог посуды с собственной админкой (в разработке — см. `.claude/plans` для полного плана и порядка фаз).

## Стек

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- Neon Postgres + Drizzle ORM (подключается на этапе P1)
- Vercel Blob для фото товаров (этап P3)

## Запуск локально

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Сейчас (этап P0) каталог и товары — заглушки из `src/lib/placeholder-data.ts`, база данных ещё не подключена.
